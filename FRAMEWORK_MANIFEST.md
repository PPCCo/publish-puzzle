## Safety defaults


- External writes: disabled.
- The six human gates (niche, interior, cover, compliance, listing, release) and release authorization: human-only.
- Content: generated by code and independently verified by code.
- Coloring line art: original only.
- Project state: JSON/YAML plus append-only NDJSON events.
- PostgreSQL, Temporal, Redis, Kubernetes, and the Claude Agent SDK: not required.
