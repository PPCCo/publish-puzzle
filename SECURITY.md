# Security & Safety Policy

## SEC-001 — Threat model

This framework runs autonomous agents that generate content and assemble upload-ready
packages. The primary risks are: unauthorized external side effects (publishing,
spending, listing changes), rights/IP infringement, unsafe child-facing content,
prompt injection via retrieved data, and unverifiable quality claims.

## SEC-002 — External writes disabled by default

`.claude/settings.json` sets `PUBLISHING_EXTERNAL_WRITES=disabled`. The framework
never publishes, submits, unpublishes, or edits a live listing on KDP, Etsy, Gumroad,
or any channel; never spends money or launches paid advertising; never purchases
identifiers; never accepts legal terms or creates accounts. `product-submit` only
records a manual submission or prepares a request payload.

## SEC-003 — Human-only actions

The six human gates (niche, interior, cover, compliance, listing, release) and release
authorization are human-only. Their skills carry `disable-model-invocation: true`;
Claude cannot invoke them. Release authorization requires two approvers bound to exact
package hashes.

## SEC-004 — Content integrity

Content is generated by code and independently verified by code. A generator never
certifies its own solvability, uniqueness, answer-key correctness, or difficulty.
Verification results are content-addressed; approvals bind to exact artifact hashes and
are invalidated when an input hash changes.

## SEC-005 — Rights and originality

Coloring line art is original only: no tracing, no derivative of a protected image, and
no imitation of a named living artist. A rights ledger records provenance and licensing
for line art, fonts, clip elements, and word lists. Unresolved rights, trademark, or
child-safety issues block release and escalate to a human. Rights agents identify
issues; they are not legal counsel and do not accept terms.

## SEC-006 — Prompt-injection defense

Retrieved text and reference material are treated as untrusted data, never as
instructions. Hooks and the pre-tool policy deny out-of-scope tool use, and the
subagent-event/stop-audit hooks record activity for review.

## SEC-007 — Secrets

Secrets live only in explicitly configured environment variables, never in the
repository. `.env.example` documents variable names without values. Hooks and the MCP
server do not expose unpublished content or secrets to unapproved services.

## SEC-008 — Reporting

Use the human-only `/product-incident` skill to record a safety, rights, or release
incident. It does not itself remediate a live listing; it prepares the human action.
