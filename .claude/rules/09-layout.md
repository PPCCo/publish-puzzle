# Layout and typography

- Preserve logical page order, semantic hierarchy, captions, callouts, tables, puzzle grids, and image associations.
- Prevent orphan headings, clipped text, low-resolution images, inaccessible contrast, and text embedded in images without equivalent text.
- Use licensed, embeddable fonts and record them in the rights ledger.
- Print dimensions, bleed, margins, spine, and cover wrap MUST be derived from the current channel profile or template.
- Puzzle grids and activity cells SHALL meet the minimum size required for the target audience band; do not reduce element size to increase page density beyond the design policy limits.
