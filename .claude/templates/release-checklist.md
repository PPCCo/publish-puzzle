# Release checklist

- [ ] Current interior and cover hashes match content-freeze approval
- [ ] All blocker and major findings are closed and independently verified
- [ ] All puzzles verified solvable with correct solutions by script (not agent assertion)
- [ ] Difficulty labels match measured difficulty; answer-key completeness confirmed by script
- [ ] Rights ledger covers every included release asset (line art, fonts, word lists, generated assets)
- [ ] Originality attestation on record for all coloring line art and custom illustrations
- [ ] Accessibility checks passed or documented manual exceptions are approved (contrast, type size, alt text)
- [ ] Print preflight passed: trim, bleed, margins, fonts embedded, image resolution, colour handling
- [ ] Digital-PDF preflight passed where applicable: page size US Letter/A4, DPI >= 300, all fonts embedded
- [ ] Physical print proof approved for paperback/hardcover
- [ ] Canonical metadata and platform variants reviewed (KDP, Etsy, Gumroad as applicable)
- [ ] Prices, territories, channels, and product types approved
- [ ] Final approval recorded against exact hashes
- [ ] Release authorization has required distinct approvers and is unexpired
- [ ] Platform rules were refreshed before submission (KDP content policy, Etsy listing rules, Gumroad terms)
- [ ] External submission will be performed manually or through a separately reviewed connector
