# SIL Open Font License 1.1 — reference

- **SPDX identifier:** `OFL-1.1`
- **Canonical text:** https://openfontlicense.org/open-font-license-official-text/
- **Steward:** SIL Global (SIL International)

This file is an evidence **pointer**, not the license body. The full verbatim OFL 1.1
text is NOT stored inline here (kept out to avoid pasting large legal boilerplate).
To hold a local copy alongside a bundled font, drop the official `OFL.txt` that ships
with the font next to the font file and add its path to the font's `evidence_paths`.

## Permission summary (informal — the canonical text governs)

The OFL 1.1 permits use, study, modification, and redistribution of the fonts,
**including embedding in documents and bundling with commercial products**, at no
cost, provided that:

- fonts are not sold by themselves;
- Reserved Font Names (if declared) are not reused by modified versions;
- the license and copyright notice travel with the font and any derivative.

Embedding a font in a book's EPUB/PDF interior and selling that book is expressly
allowed. No royalty or per-title fee applies.

Each registered font family in `.claude/config/dependencies.default.json` records its
own `license_reference` (`OFL-1.1`), `embedding_allowed`, and `commercial_use_verified`
flags; this file is the shared reference those entries point at.
