# Apache License 2.0 — reference

- **SPDX identifier:** `Apache-2.0`
- **Canonical text:** https://www.apache.org/licenses/LICENSE-2.0
- **Steward:** The Apache Software Foundation

This file is an evidence **pointer**, not the license body. The full verbatim
Apache-2.0 text is NOT stored inline here (kept out to avoid pasting large legal
boilerplate). To hold a local copy alongside a bundled font, drop the official
`LICENSE`/`LICENSE.txt` that ships with the font next to the font file and add its
path to the font's `evidence_paths`.

## Permission summary (informal — the canonical text governs)

The Apache License 2.0 grants a perpetual, worldwide, royalty-free copyright
license to use, reproduce, modify, and redistribute the work and derivative works,
**including embedding in documents and bundling with commercial products**, provided
that:

- the license and any NOTICE file travel with redistributed copies;
- modified files carry prominent change notices;
- the ASF trademarks are not used except as required for reasonable/customary use.

Unlike the OFL, Apache-2.0 has **no Reserved Font Name mechanism** and no
"must-not-be-sold-alone" clause. Embedding an Apache-2.0 font in a book's EPUB/PDF
interior and selling that book is expressly allowed. No royalty or per-title fee
applies. An explicit patent grant is included.

Each registered font family in `.claude/config/dependencies.default.json` records its
own `license_reference`, `embedding_allowed`, and `commercial_use_verified` flags;
this file is the shared reference Apache-2.0 entries point at.
