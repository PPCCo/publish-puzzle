# Dynamic Workflows

Dynamic workflow scripts require Claude Code 2.1.154 or later; the full framework requires 2.1.217 or later because it configures nested and concurrent subagent limits. They coordinate parallel subagents with `agent()` and `pipeline()` and return a final synthesis. The workflow runtime itself does not access the filesystem or shell; spawned agents do that under normal permissions and hooks, running the deterministic `ph_cli.py` verbs.

Content is **generated by code and independently verified by code**: no workflow lets a generator sign off its own solvability, uniqueness, answer-key, or difficulty claims. Human approvals are deliberately outside workflows because saved workflows cannot collect mid-run human input. Run a stage workflow, inspect its output, then invoke the corresponding human-only approval skill (`/product-approve-*`, `/product-freeze`, `/product-release-authorize`).

| Workflow | Purpose |
|---|---|
| `niche-opportunity-scan` | Dated puzzle/coloring/journal/printable niche discovery and cross-checking across independent evidence lenses |
| `content-generation-fanout` | Parallel deterministic code generation of content batches, then independent code verification and synthesis |
| `content-verification-batch` | Independently verify already-generated batches by code (solvability, uniqueness, answer key) and synthesize a finding register |
| `difficulty-audit` | Per-batch measured-versus-labeled difficulty check by code plus progression-fit synthesis |
| `coloring-line-art-review` | Per-asset originality, printability, contrast, and age-fit review plus deduplicated synthesis |
| `product-multi-review` | Multi-dimensional independent product review with integrity verification and synthesis |
| `accessibility-audit-batch` | Parallel accessibility, contrast, legibility, and print-at-home audits plus synthesis |
| `metadata-channel-audit` | Canonical/channel metadata consistency and per-channel (KDP/Etsy/Gumroad/generic) compliance |
| `marketing-asset-fanout` | Per-channel listing/marketing brief drafting from approved metadata plus compliant synthesis |
| `final-red-team` | Complete release-candidate adversarial audit across solvability, originality, rights, accessibility, and packaging lenses |
| `approval-packet-audit` | Gate-packet readiness (niche/interior/cover/compliance/listing/release) without granting approval |
| `autonomous-run-loop` | Advance one product through valid non-gate stages, stopping at every human gate with a prepared packet |
