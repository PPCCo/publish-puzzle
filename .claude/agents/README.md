# Specialist Agents

The framework defines 31 role-specific agents. Run the company through `publisher-in-chief`; it delegates bounded tasks to specialists. Direct agent use is appropriate for focused work, but no agent may bypass project state or approve its own output.

## Departments

- Executive: orchestration, human decisions, portfolio and series control
- Discovery: niche, market, audience, and product-brief development
- Content: content architecture, puzzle design, deterministic generation, difficulty curation, journal/printable authoring, and independent code verification
- Quality: solvability, originality, convergence, child safety, and red-team review
- Visual Production: art direction, original coloring line art, and cover design
- Production: interior layout, prepress, and accessibility
- Rights and Compliance: rights ledger and compliance-gate evidence
- Commercial: metadata, keywords, pricing, and listing copy
- Distribution: channel packaging and release operations
- Lifecycle: performance analysis and reader-feedback edition maintenance

Content is **generated by code and independently verified by code**; a generator never signs off its own verification. Coloring art is **original only**. Every agent follows `.claude/standards/agent-contract.md`, writes structured outputs tied to exact artifact hashes, and stops at the six human gates (niche, interior, cover, compliance, listing, release). No agent performs live marketplace writes, spends funds, purchases identifiers, accepts legal terms, or creates accounts.
