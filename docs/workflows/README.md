# Workflow Roadmap

This roadmap maps the product lifecycle to the dynamic workflows in
`.claude/workflows/`. Workflows fan out to independent subagents and fan in to a
synthesis; they never grant a gate, freeze, release, or submit.

| Lifecycle stage | Workflow | Human gate that follows |
|---|---|---|
| Discovery / niche assessment | `niche-opportunity-scan` | niche |
| Content generation | `content-generation-fanout` | — |
| Content verification | `content-verification-batch` | — |
| Difficulty QA | `difficulty-audit` | — |
| Multi-dimension review | `product-multi-review` | interior |
| Line-art review | `coloring-line-art-review` | cover |
| Accessibility | `accessibility-audit-batch` | compliance |
| Metadata | `metadata-channel-audit` | listing |
| Marketing | `marketing-asset-fanout` | listing |
| Release candidate | `final-red-team` | release |
| Gate readiness | `approval-packet-audit` | any |
| Whole-run advance | `autonomous-run-loop` | stops at each gate |

## Principles

- Content is generated by code and independently verified by code; no workflow lets a generator self-certify.
- Human approvals live outside workflows because a saved workflow cannot collect mid-run human input.
- The workflow runtime cannot touch the filesystem; spawned agents run `ph_cli.py` under normal permissions and hooks.
